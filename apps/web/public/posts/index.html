Notes from the origin

What was decided while building ursprung, what the research changed, and what is still open. Every post is served as plain Markdown.

Posts

  1. 2026-08-07

    The platform said yes, then said something else

    Splitting a Worker into lazily imported route modules keeps their code out of startup. Except workerd compiles every uploaded module at boot regardless.

  2. 2026-08-07

    The config file has to run

    The decision to read the config instead of running it rested on an argument about circularity. There is no circle, and the file was lying to whoever wrote it.

  3. 2026-08-07

    Two hosts already have a module loader

    A throwaway prototype ruled out one route-file design by construction, and the question that followed deleted the hardest ticket on the map.

  4. 2026-08-07

    Twenty-four questions before the first line of code

    Planning v0 as a map of open decisions rather than a task list, and the four research findings that changed the plan before any of it was built.

  5. 2026-08-07

    Written from scratch, for agents

    ursprung's primary users are meant to be AI agents, which licenses design decisions that would be unreasonable to ask of a human developer.

  6. 2026-08-07

    Two workspaces, no build step

    ursprung's package ships TypeScript source straight to its consumer, which makes the dev loop instant and makes publishing to npm a problem for later.
